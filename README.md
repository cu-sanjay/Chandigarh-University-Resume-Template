# About The Template

CU Resume is a professionally designed ATS-friendly LaTeX resume template inspired by the Chandigarh University placement resume format.

The template is specially optimized for:

- Software Engineering Internships
- Campus Placements
- Full-Time Developer Roles
- Computer Science Students
- Modern ATS Resume Screening Systems

This template focuses on clean typography, compact spacing, professional hierarchy, and recruiter-friendly formatting while maintaining a modern visual appearance.

# How To Use

**[Copy on Latex](https://www.overleaf.com/read/zdykwjpvsvnq#0ebf61)**

Or

## 1. Clone Repository

```bash
git https://github.com/cu-sanjay/Chandigarh-University-Resume-Template
```

## 2. Open In Overleaf

Upload all files directly to:

https://www.overleaf.com

## 3. Update Your Information

Edit:

```latex
main.tex
```

Replace:
- Name
- Contact Information
- Projects
- Experience
- Certifications
- Skills

## 4. Add Profile Picture

Upload your passport-size image in the project folder and replace:

```latex
profile-placeholder.jpg
```

The template automatically:
- preserves aspect ratio
- avoids stretching
- adds a professional thin border
- maintains passport-photo appearance
